# F0 设备验收步骤

在 Windows x64 与 Android arm64 各运行一次。记录设备与系统版本、Flutter 版本、构建模式和结果；模拟器结果单列。

1. 冷启动：显示暖杏陶土色中文封面与落日线条。点「开始记录」后，落日线条在初始化期间逐渐绘出，然后进入记录页；未配置远端模型也能打开。
2. 输入中文并使用输入法候选；按 Enter 只确认候选或换行，不提交记录。
3. 输入一句话后等待模拟保存确认；关闭应用再打开，演示内容应消失，界面必须事先明确说明这一点。
4. 再输入一段并点「收好这一刻」；「片段」页可见该文字。
5. 模拟保存失败时，编辑框内容仍在，按「重试」后状态恢复。
6. 检查 320 px 窄窗、桌面宽窗、深浅色和系统字体放大：封面的开始按钮、输入框、完成按钮及导航始终可达。打开系统减少动画后，加载线条应保持静态。
7. 点录音/附件按钮：只能看到尚未接入说明，不出现虚假的正在录音或已导入状态。

F0 的 Mock 验收仅证明界面和接口调用路径；真实持久化、长录音与文件导入按后续任务验收。
